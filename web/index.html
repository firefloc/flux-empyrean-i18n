Flux Empyrean — traduction expérimental

Outil communautaire, en cours de mise au point. Ton jeu ne quitte pas ton navigateur. La traduction française a été produite par une IA, avant que quiconque ait terminé le jeu — attends-toi à des maladresses, et signale-les.

Jouer en français, sans ligne de commande

Le mod ne contient aucun fichier du jeu — 210 Ko de texte et de Lua. Les écrans traduits sont fabriqués par le jeu lui-même au premier lancement, depuis ta propre copie. Rien n'est téléversé, tout se passe dans ton navigateur.

1.
Le chargeur GDPatch. Récupère-le pour ta plateforme sur leur page de releases — libgdpatch_loader.so si Steam t'a livré le jeu Linux, gdpatch_loader.dll s'il t'a livré le jeu Windows — y compris si tu le fais tourner sous Proton ou Wine : c'est le binaire du jeu qui décide, pas ton système. La page te dira lequel elle a trouvé. Le chargeur appartient à ses auteurs, on ne le redistribue pas.
2.
La traduction.

Le navigateur te demandera le dossier du jeu — celui qui contient flux-empyrean.x86_64 ou Flux Empyrean.exe. Il n'y écrit que GDPatch/, et ne touche à rien d'autre.

3.
Lancer le jeu deux fois. Le premier lancement fabrique les écrans traduits — quelques secondes, une seule fois. L'interface passe en français au lancement suivant, et se refait toute seule quand le jeu se met à jour. Plateforme détectée : .
4.
Si tu joues sous Proton ou Wine, une ligne à coller dans les options de lancement Steam du jeu :
WINEDLLOVERRIDES="winmm=n,b" %command%
Sans elle, Wine ne charge jamais le mod — et ne dit rien. Sous Windows véritable, il n'y a rien à faire.
Attention : sous Proton, le jeu lui-même souffre d'un défaut d'entrée — les clics ne répondent pas dans les menus. C'est vérifié sans le mod : ce n'est pas la traduction. Essaie de maintenir le clic droit pendant le clic gauche, désactive Steam Input, ou change de version de Proton. Le dépôt Linux natif, lui, fonctionne.
4.
Jeu Linux natif uniquement — pas sous Proton — il reste une ligne à coller dans les options de lancement Steam du jeu :
./run_with_gdpatch.sh %command%
Ce script se récupère sur gdpatch.dev et se pose à côté du chargeur. Il est nécessaire parce que le chemin d'installation Steam contient une espace, sur laquelle LD_PRELOAD découpe. Avec le jeu Windows — natif ou sous Proton — la DLL se branche seule, il n'y a rien à régler.

Comment ça marche

Cet éditeur ne contient aucun texte du jeu — c'est volontaire, la prose appartient à son auteur. Il lit le pack de ta propre copie, ici, dans ton navigateur. Rien n'est téléversé, il n'y a ni serveur ni compte.

1. Ouvre le fichier du jeu : flux-empyrean.x86_64 sous Linux, Flux Empyrean.exe sous Windows, ou le .pck s'il est séparé. La page en lit le sommaire et n'extrait que les quelques centaines de kilooctets qui portent du texte — le fichier fait 827 Mo, il n'est jamais chargé en entier.

C'est aussi ce qui distingue le jeu complet de la démo : la traduction se construit à partir de ton corpus. Sans le jeu, l'éditeur n'a simplement rien à afficher.

2. Charge une traduction existante pour la corriger — les fichiers documents.json, scenes.json et scripts.json d'une langue — ou commence à vide.

3. Édite la colonne de droite, puis Proposer au projet : tes trois fichiers se téléchargent et GitHub s'ouvre sur la page de dépôt, qui crée la pull request pour toi. La validation automatique du dépôt rejouera les contrôles d'énigmes avant toute fusion.

Les lignes en orange sont gelées : blocs chiffrés, langue construite, rébus. Le jeu retire tout ce qui n'est pas une lettre avant de déchiffrer — une lettre en plus décale tout le message. L'éditeur les met en lecture seule.
